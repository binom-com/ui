# @binom/ui 0.1.0: основа оформления для всех приложений Binom

**Дата:** 2026-11-10
**Владелец дизайн-системы:** Кирилл Столяров (дизайнер).
**Источник значений:** chat.binom.com (`binom-com/chat`, коммит `0aec780`), уже вынесенный в Ideas (`binom-com/Ideas`, `app/web/src/binom-ui/`, PR #8).
**Пример устройства:** `kanbanchi/Kanbanchi-UI` (открытый, ставится из GitHub).

## 0. Зачем

Пять приложений Binom (Chat, Ideas, Meet, Calendar, Synergy) оформлены пятью разными способами. Первый шаг к единому UI — общая **основа**: шрифт, токены, светлая и тёмная темы, общие правила для элементов. Один пакет, одинаковый вид, без ручных копий значений.

| Приложение | Стек | Что подключает |
|---|---|---|
| Chat, Ideas | React 18, обычный CSS | `theme.css` (токены + шрифт + общие правила) |
| Calendar | React 19, Vite, Tailwind 4 | `tailwind.css` (токены как тема Tailwind) |
| Synergy | Next.js 16, Tailwind 4 | `tailwind.css` |
| Meet | React 18, Material UI 5 | тема Material UI из пакета + `tokens.css` |

## 1. Один источник — файл токенов

- `tokens/tokens.json` в формате W3C Design Tokens (`$value`, `$type`), группы `light` и `dark` для цветов и теней, общие для остальных (радиусы, размеры, анимации, шрифт).
- Значения и имена — ровно те, что сейчас в `binom-ui/theme.css` Ideas (то есть из чата). Ничего не придумывается.
- Этот же файл импортируется в Figma Variables (плагин Tokens Studio понимает этот формат): режимы Light/Dark.
- Всё остальное **собирается** из него скриптом и лежит в `dist/` (собранные файлы хранятся в репозитории, чтобы приложениям не нужно было ничего собирать при установке).

## 2. Что собирается

- `dist/tokens.css` — CSS-переменные: светлые на `:root`; тёмные и под `@media (prefers-color-scheme: dark) { :root:not([data-theme='light']) }`, и под `:root[data-theme='dark']` (тема системы и выбор в настройках); блок «меньше движения» (`prefers-reduced-motion`).
- `dist/fonts.css` + `fonts/` — DM Sans Variable, свои файлы, лицензия SIL OFL.
- `dist/base.css` — общие правила элементов из чата (кнопки: основная, обычная серая, текстовая, красная; поля и фокус; прокрутка; зоны касания; тонкие иконки Lucide; обратная связь при касании без «залипания» наведения).
- `dist/theme.css` — всё вместе: шрифт + токены + общие правила. Для Chat и Ideas.
- `dist/tailwind.css` — для Tailwind 4: токены объявлены через `@theme`, так что классы вида `bg-page`, `text-muted`, `rounded-lg`, `shadow-dialog` берут значения Binom; тёмная тема подменяет те же переменные. Общие правила элементов — по желанию, отдельным импортом.
- `dist/mui.js` (+ `.d.ts`) — `createBinomTheme(mode: 'light' | 'dark')`: настройки темы Material UI 5 (палитра, шрифт, скругления, тени) из тех же значений.

## 3. Как подключают

- Установка из GitHub по метке версии, архивом по HTTPS: `"@binom/ui": "https://github.com/binom-com/ui/archive/refs/tags/v0.1.0.tar.gz"` (вид `github:…#v0.1.0` npm превращает в скачивание через git по SSH, а в сборочных образах Railway нет ни git, ни ключей). Реестр пакетов не нужен; переход на него потом меняет только эту строку.
- Репозиторий открытый (как Kanbanchi-UI), чтобы сборкам на Railway не нужны были ключи. Решение за админом; пока репозиторий закрыт, пакет готовится, но приложения его не подключают.
- Новая версия — новая метка (`v0.2.0`), приложение меняет одну строку.

## 4. Правила развития

- Значения меняются только в `tokens/tokens.json`, затем пересборка; руками `dist/` не правится (тест это проверяет).
- Изменение вида утверждает владелец дизайн-системы. Перед слиянием — ревью на Opus.
- Приложения не переопределяют общие токены; своё (например, цвета типов в Ideas) живёт в приложении поверх общих.
- Компоненты и общая шапка Binom — следующие версии, не эта.

## 5. Первые подключения

- Ideas — первым: заменяет папку `app/web/src/binom-ui/` на пакет. Вид не меняется.
- Chat — пулл-реквест (есть запись).
- Meet, Calendar, Synergy — пулл-реквесты, если дадут запись; иначе готовые патчи (`git apply`) с проверкой, что приложение собирается.

## 6. Проверка

- Собранные файлы совпадают с тем, что даёт скрипт из `tokens.json` (иначе тест падает).
- `tokens.css` и `theme.css` дают те же значения, что `binom-ui/theme.css` Ideas сейчас.
- Тестовая сборка Tailwind 4 с `tailwind.css`: классы `bg-page`, `text-text`, `rounded-xl` получают значения Binom, в тёмной теме — тёмные.
- `createBinomTheme('light' | 'dark')` проходит через `createTheme` Material UI 5 без ошибок, цвета совпадают с токенами.
- Ideas после перехода на пакет: тесты, сборка, снимки до и после совпадают.
